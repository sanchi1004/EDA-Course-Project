# Breast Cancer Exploratory Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Breast Cancer dataset. The objective is to understand the dataset through statistical analysis, data preprocessing, and various visualizations.

## Dataset
- Source: https://raw.githubusercontent.com/salemprakash/EDA/main/Data/bcancer.csv

## Phase 1 Tasks Completed
- Loading the dataset
- Basic statistical analysis
- Handling missing data
- Data cleaning
- Data transformation
- Univariate analysis - (Histogram (`radius_mean`), Box Plot (`texture_mean`), Count Plot (`diagnosis`))
- Bivariate analysis (3 visualizations) - (Scatter Plot (`radius_mean` vs `texture_mean`), Bar Plot (`diagnosis` vs `area_mean`), Box Plot (`diagnosis` vs `perimeter_mean`))
- Multivariate analysis - (Correlation Heatmap, Pair Plot, Violin Plot (`diagnosis` vs `radius_mean`))

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
